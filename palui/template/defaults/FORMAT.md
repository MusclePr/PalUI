# defaults/*.env ファイルのフォーマット説明

## 概要

- 環境変数 KEY=VALUE の羅列であり、シェルスクリプトやGUIから参照されます。
- #で始まるコメントの書式内容に応じてUI構築が行われます。

## コメント書式（UI構築用）

- 見出し
  - `#*見出し１` … 見出し１
  - `#**見出し２` … 見出し２＋折りたたみ機能付き（デフォルト値と異なる場合に展開表示されます）
  - `#***見出し３` … 見出し３
- 入力フォーム … 直後の KEY=VALUE に対するUI修飾を与える
  - `#|ラベル|型|説明文`
    - ラベル：文字列ですが、`|`はセパレータなので使用できません。
    - 型：
      - `BOOL` … True/False
      - `INT` … 整数
      - `INT(最小値,最大値)` … 範囲付き整数
      - `FLOAT` … 浮動小数点
      - `FLOAT(最小値,最大値)` … 範囲付き浮動小数点
      - `STR` … 文字列
      - `PASSWORD` … 隠匿文字列
      - `ARRAY` … 任意の文字列の配列：`KEY=(VALUE1,VALUE2,VALUE3)`
      - `CHOICE(VALUE1,VALUE2,VALUE3)` … VALUE1かVALUE2かVALUE3の中から１つ選択するUI。決定される書式例：`KEY=VALUE2`
      - `SELECT(VALUE1,VALUE2,VALUE3)` … VALUE1かVALUE2かVALUE3の中から複数選択するUI。決定される書式例：`KEY=(VALUE1,VALUE3)`
    - 説明文：行末まで説明文です。型やレイアウトによって、表現方法は可変します。
  - 例）
    「MOD有効」とラベルされたトグルスイッチが配置され、説明文が併記されます。
    ```ini
    #|MOD有効|BOOL|Modを有効にします
    MOD_ENABLED=True
    ```
